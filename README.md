## 🧠 Engineering Themes Across My Repositories

### 1. Building useful AI instead of isolated demos
My AI projects focus on complete user workflows: collecting input, deciding what tools are needed, retrieving information, managing state, presenting results, and making sources visible to the user.

### 2. Connecting excellent UX to reliable backend systems
I enjoy working across the full product boundary—from responsive React interfaces and design systems to APIs, authentication, persistence, and deployment-oriented architecture.

### 3. Learning through multiple technology ecosystems
My work spans Python, JavaScript/TypeScript, Java, Spring, Node.js, Django, FastAPI, GraphQL, SQL, NoSQL, and cloud tooling. This helps me select technologies based on the problem rather than relying on a single stack.

### 4. Treating security and accessibility as product features
My projects include security learning through CTF applications and accessibility-minded frontend work such as keyboard navigation, focus states, semantic markup, responsive layouts, and reduced-motion support.
